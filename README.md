О проекте: 
Исследование данных резюме соискателей с целью изучения распределения зарплатных ожиданий и факторов, связанных с их уровнем.

Выполнено в проекте:
Проведена первичная проверка и очистка данных.
Обработаны пропуски, дубликаты и некорректные значения.
Исходные составные значения преобразованы и разделены на отдельные признаки для дальнейшего анализа.
Объединены данные из нескольких таблиц для актуализации значений валют и последующего пересчёта зарплатных ожиданий.
Данные приведены к удобному для анализа формату.
Выделены и обработаны аномальные значения.
Проведён исследовательский анализ данных.
Исследована взаимосвязь зарплатных ожиданий с опытом работы, возрастом, образованием и другими характеристиками соискателей.
Проведено сравнение зарплатных ожиданий между различными группами кандидатов.
Построены визуализации для анализа распределений и выявления закономерностей.
